# Captured CDINT Grid Skills

This directory is the complete captured CDINT procedure corpus. Each skill is
intentionally verbatim from the captured source except for an HTML TBD comment
that defers compatibility decisions.

These skills are not selected by QMR `agents.yaml` and are not safe or expected
to run in `todo_app_project` until their dependencies are configured. Current
Mogent does not install or select Agent Skills. Use this corpus for inspection
and dogfooding only.
