# QMR Skills

Triggered procedures for QMR's personal library. Each directory contains one
`SKILL.md` with Agent Skills `name` and `description` frontmatter.

See [skill provenance](provenance.md) for source history and review boundaries.

These skills are ready for a skill-aware consumer to install or invoke. Mogent
does not yet select, install, or render skills from an `agents.yaml` manifest.
Do not add a skill to an `AGENTS.md` render as a substitute for integration.

DR/DI creation remains in
`proposals/records-and-thought-experiments/` until a target repository adopts
its record locations and identifier convention.
