# Edit A Filed Thought Experiment

## Read The Relevant Record

Read the affected TE, locally available TEs that directly cite it or are cited by
it, and relevant local editing-policy refinements. For an obvious typo or a
demonstrably moved current path, the affected TE may be sufficient.

## Preserve Historical Analysis

Update a path in place only when it names a current location. Preserve paths and
wording that describe historical state, quotations, attribution, refinements,
supersedence, or decision history. When uncertain, treat the text as historical.

For a vocabulary update whose meaning does not change, preserve historical
quotations and note the change using the target repository's record convention.

## Refine Or Supersede

Append a dated refinement for a navigational update or resolved implication. Do
not rewrite the historical body merely to make it current.

Create a new superseding TE when a conclusion, scope, applicability, or locked
decision meaning changes. Update the older TE only enough to identify its
successor according to the target repository's convention.

## Verify

Confirm that historical claims remain historical, current pointers are accurate,
and substantive changes live in a successor rather than a rewritten analysis.
